# Bidly

Online auction site for the Java EE course (JSF + EJB + JPA + JMS).

Needs a Jakarta EE 10 server with the H2 driver. The datasource and the JMS queue are
defined in web.xml so nothing has to be set up in the server. Data goes to ./bidly-data.
